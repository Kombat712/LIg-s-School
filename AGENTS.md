## 1. Окружение разработчика

- **ОС**: Windows 10
- **Редактор**: Visual Studio Code
- **Терминал**: Visual Studio Code

### Необходимые инструменты
- **Node.js** (версия LTS, рекомендуется 18.x или 20.x)
- **npm** (поставляется с Node.js)
- **.NET SDK** (версия указана в `global.json` или в `.csproj` файле бэкенда; обычно .NET 6/7/8)
- **PostgreSQL** (установлен локально)
- **pgAdmin** (для визуальной работы с БД)
- **Git** (система контроля версий)

---

## 2. Структура проекта

- **`frontend/`** – React-приложение (Create React App / Vite)
- **`backend/`** – ASP.NET Core Web API
- Корень проекта содержит данный `AGENTS.md`, возможно `.gitignore`, `README.md` и другие общие файлы.

---

## 3. Сборка и запуск

### 3.1. База данных (PostgreSQL)

1. Убедитесь, что сервер PostgreSQL запущен (обычно работает как служба Windows).
2. При необходимости создайте базу данных вручную через pgAdmin или командную строку.  
   Название БД и данные для подключения ищите в строке подключения (см. `backend/appsettings.Development.json` или User Secrets).
